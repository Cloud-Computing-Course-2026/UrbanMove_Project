# Análisis del Enunciado - URBANMOVE

Este documento recoge el desglose de los 18 apartados de la especificación oficial de Computación en la Nube (ULPGC):
- Mínimos para aprobar (10 microservicios obligatorios, 3 Lambdas, Data Lake con 3 capas, 4 marts, 3 clientes).
- Modelo de concurrencia y no solapamiento de reservas.
- Integración asíncrona desacoplada mediante bus de eventos.
