UrbanMove · Viajes

Este microservicio permite iniciar, consultar y finalizar viajes. Las operaciones se realizan mediante peticiones HTTP a la API.

  • Contrato de la API (OpenAPI YAML)
  • Estado del servicio

Operaciones disponibles

MétodoRutaOperación
POST/ridesIniciar un viaje
GET/rides/{id}Consultar un viaje
POST/rides/{id}/finishFinalizar un viaje

Las peticiones POST requieren la cabecera Idempotency-Key y un cuerpo JSON según el contrato de la API.
