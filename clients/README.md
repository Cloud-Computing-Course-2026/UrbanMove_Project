# URBANMOVE - Client Applications

Esta carpeta contiene las aplicaciones clientes e interfaces de usuario del ecosistema URBANMOVE:

- `users/`: Aplicación móvil/web para usuarios finales (registro, búsqueda de vehículos, reservas y viajes).
- `maintenance/`: Aplicación para operadores de campo y talleres (estado de batería, bloqueos, traslados y reparaciones).
- `dashboard/`: Panel web administrativo y analítico para la monitorización de flotas en tiempo real.
